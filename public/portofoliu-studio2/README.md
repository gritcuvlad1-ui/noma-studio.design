# NOMA Studio — Main Portfolio Assets

Acest folder conține imaginile oficiale de portofoliu ale studioului NOMA.

## Ghid de utilizare:
1. Copiați aici imaginile primite de la clienți sau randările oficiale (de preferat în formate optimizate web precum `.webp` sau `.jpg`).
2. Adăugați referințele către aceste imagini în fișierul `src/data/projects.ts`.
